# Art drop-in

Makko.ai-generated assets for the active variant go here (WebP, sprite-packed), named per the theme pack's `icon`/`bg` fields. The full per-game manifest is in `docs/IDLE_FORGE_ENGINE_SPEC.md` Part J. The engine renders text/procedural fallbacks when a file is missing, so the game is playable before art lands — but never ship a variant without its bespoke set (originality rule, spec Part F).
