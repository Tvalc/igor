## Protocol

1. A fresh account on each tool's free tier. Paid features are noted separately.
2. The prompt above is pasted verbatim as the first message.
3. Up to three follow-up prompts are allowed, chosen from a fixed list: "fix any bugs you see", "make the controls feel tighter", "add the missing features from the original request".
4. We record time to first playable build, which requested features work, export options offered, and cost.
5. Every output is saved: screenshots, a short gameplay capture, and a playable link or build where the tool allows it.

## Scoring

Each tool gets a hands-on score out of 10:

- Feature completeness (4 points): one point per working core feature (movement and jumping, collectibles and score, hazards and lives, levels and game over).
- Playability (3 points): controls, collision and difficulty curve.
- Speed and effort (2 points): time and number of follow-ups needed.
- Export (1 point): whether a usable build can leave the platform.

The hands-on score is blended 50/50 with the facts-based score on each tool's page once results are published.
